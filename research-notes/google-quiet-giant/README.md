This folder holds the source for an interactive page. GitHub shows `index.html` as code; the link above opens it as the page.

**The model:** [Does AI Capex Pay Back - Model v1.xlsx](./Does%20AI%20Capex%20Pay%20Back%20-%20Model%20v1.xlsx). Every assumption sits on the Inputs sheet; change one and it flows through to the cohort, scenario and fleet sheets. Open the About sheet first.
