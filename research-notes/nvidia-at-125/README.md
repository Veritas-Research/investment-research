# NVIDIA at $125

**Read the page:** [NVIDIA at $125: Is the Business Still Solid, and Is the Stock Undervalued?](https://veritas-research.github.io/investment-research/research-notes/nvidia-at-125/)

This folder holds the source for an interactive page. GitHub shows `index.html` as code; the link above opens it as the page.

**The model:** [NVIDIA Valuation - Damodaran Engine - Model v1.xlsx](./NVIDIA%20Valuation%20-%20Damodaran%20Engine%20-%20Model%20v1.xlsx). It is Aswath Damodaran's own valuation spreadsheet with NVIDIA's numbers on the Input sheet; change one and the value flows through. The [model folder](./model) has the same math in Python and JavaScript, including the 3 year check, and the calculator on the page uses it.

Prices are as of the November 20, 2026 close. A follow up will rerun the same model after NVIDIA files its quarterly report (10-Q), due about December 4, 2026.
